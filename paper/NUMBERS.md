# Numbers in `paper/main.tex` and where they come from

Every numeral in the body of `paper/main.tex` is covered by a row below. `paper/check_numbers.py` re-reads each source, applies the locator and format, requires the result to equal the printed text, and requires the printed text to appear on a line of `main.tex` that also contains the context. It also fails if a rounding is ambiguous (for example a four-decimal source value ending in 5 rounded to three decimals) and if any numeral in the body of `main.tex` is not accounted for here.

Paths are relative to the project root. Locators are Python expressions over the helpers in `check_numbers.py` (`csvv` reads CSV cells by filter, `rx` reads a regular-expression group from a text file, `js` reads JSON, `spec` reads the household specification, `gelapsed`/`gdate`/`gsubject` read git history, `num` reads a number and tracks its rounding). Format tokens: `r<n>` round to n decimals, `p<n>` percent, `i` integer, `c` integer with thousands commas, `s` text; flag `+` prints an explicit plus sign. In regular expressions `\x7c` stands for a literal vertical bar.

Sources marked PROTOCOL.md or examples/household/spec.json are design parameters (frozen inputs), not results.
